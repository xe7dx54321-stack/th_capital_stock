# Frozen Phase contracts

This directory contains Phase-era runners and their contract tests after they
leave the default runtime and test discovery paths.

The files remain runnable for manual audit against the retained domain modules
under `08_scripts/lib`, but they are not scheduler, API, or `smr_app` entrypoints.

Archived groups and their pre-move verification results are recorded in
`legacy_manifest/removal-log-M5.md`.
