# 明亮研究控制台视觉规范

## 目标

将当前个人研究工作台改造成一个安静、明亮、可信赖的中文研究中枢。它服务于日常高频使用，优先保证信息层级、证据可追溯性和长时间阅读舒适度。

## 视觉方向

- 采用“企业云控制台”作为主方向，吸收少量金融编辑排版的克制感。
- 页面使用暖白底、纯白卡片、深海军蓝文字和钴蓝主色；绿色仅用于完成状态，琥珀色仅用于提醒。
- 使用三栏结构：左侧流程与档案、中间研究命令与产物、右侧证据上下文。
- 阴影保持低对比，主要依靠边框、留白和字号建立层级。
- 所有用户可见文案使用中文，代码、证券代码和证据标识除外。

## 页面结构

1. 顶栏：同行资本、个人研究工作台、今日研究状态、经典看板入口、同步档案。
2. 左栏：四个研究流程和最近运行档案，明确区分可运行与待接入能力。
3. 中栏：标的输入、四项概览指标、研究进程、研究产物。
4. 右栏：证据索引、数据新鲜度、关键判断、研究记忆审核。

## 交互原则

- 当前工作台成为默认首页；上一版 React 看板保留为“经典看板”。
- 主操作始终只有一个：开始深挖。
- 状态、事件类型、记忆状态和来源关系统一翻译为中文。
- 网络默认关闭、不会自动交易等系统边界在主操作附近持续可见。
- 旧看板与个股详情采用按需加载，避免拖慢工作台首屏。

## 清理边界

- 删除确认没有引用的占位页、空组件、阶段时间线、主题钩子、旧图标和对应 API 类型。
- 删除仅用于开发标记的页面角标插件与定位插件。
- 保留上一版看板、个股详情及其图表和信息组件。
- 更早的 Python 控制塔和静态站点生成器本轮不删除，仅退出当前前台入口；后续单独做归档迁移，避免误伤历史数据任务。
