## 4. Signal Flow Fake Signal Source

### User Observed Signals
```
21:18 易点天下 风险提示 - "卖出优先级已经足够高，应该先处理风险，再谈进攻。"
20:18 新雷能 风险提示 - "还没到必须清仓，但更适合先做减仓或降权。"
```

### Root Cause
**File**: `08_scripts/risk_engine/build_trade_risk_decision_snapshot.py`

Hardcoded summary templates:
- sell: "卖出优先级已经足够高，应该先处理风险，再谈进攻。"
- trim: "还没到必须清仓，但更适合先做减仓或降权。"
- watch: "先盯紧，不急着做大动作。"
- hold: "当前没有足够强的卖出信号。"

### Time Mechanization
Artificial timestamps generated by view model: `ts = now - timedelta(hours=idx + 1)`

### Why Entered Main Signal Flow
1. No quality gate in previous implementation
2. Hardcoded "高" strength regardless of evidence
3. No source_url/evidence_packet validation
4. Generated timestamps look recent and urgent

### Fix
Implemented quality gate in `signal_flow_view_model.py`:
- Generated_summary signals filtered from main flow
- Evidence_gaps filtered from main flow
- Added truth_status and truth_reason to all signals
