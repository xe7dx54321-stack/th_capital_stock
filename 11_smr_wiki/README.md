# SMR Wiki

`SMR Wiki` 不是原始研究材料仓库，也不是日报归档目录。

它的定位是：

- 承接 SMR 里的高价值知识
- 把研究、风险、推荐、复盘变成可复用知识对象
- 给后续的治理、审核、lint 和双 agent 协作提供稳定落点

当前目录分成四层：

- `raw/`
  - 原始资料与索引层
  - `raw/external/` 用来保存公告、新闻、网页、公开研报摘要等外部原始快照
- `wiki/`
  - 正式知识页
- `schema/`
  - 命名、录入、治理、体检规则
- `drafts/`
  - 知识草稿与人工审核导出

当前阶段必须遵守：

1. 研究卡、日报、风险预警仍然是来源，不直接等于 Wiki。
2. 高判断密度内容默认先进入 `draft`，不直接写正式知识页。
3. 正式知识页必须能回溯到来源对象。
